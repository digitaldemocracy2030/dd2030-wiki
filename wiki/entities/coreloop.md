# コアループ（Project Coreloop）

## 概要

**Project Coreloop**は、日本においてAIを活用したデジタル民主主義の「最初の成功事例」を作ることを目的とするdd2030の重点プロジェクト。単なる[[ブロードリスニング]]によるインサイト取得にとどまらず、**市民の声が政策に反映・実行され、市民満足度向上につながるという「コアループ全体の成功」**を目指す。

最初のテーマとして「オンライン広告詐欺対策」を選定。2024年に台湾で成功した事例を参考に、日本版の市民熟議プロセスを設計・実施する。2026年1月の台湾視察から始まり、通報サイト[[ストップ詐欺広告]]の公開（3月）、[[ブロードリスニング]]とワークショップ（3〜5月）、283名の市民による[[討論型世論調査]]（6月21日）を経て、2026年8月〜10月に政策提言書とプロセス再現書をまとめた。

## 「コアループ」とは何か

ゲームやアプリでユーザーが繰り返す核の行動サイクル（報酬→行動→報酬の強化ループ）の概念を民主主義に応用したもの。「声をあげれば何かが変わる」という実感を生む成功体験のサイクルを早期に実践し、複製可能にしていくことが目的。

コアループの4要素:

1. **Attentiveness（傾聴）**: [[ミニ・パブリックス]]によるオンライン市民会議で85%以上の合意リストを作成
2. **Responsibility（責任）**: 自民党PTや関係省庁が市民会議の結果を参照し政策に影響させる
3. **Competence（能力）**: Civic Techとしてリファレンスサービスを実装し行政導入を補助する
4. **Responsiveness（応答）**: 詐欺被害件数・被害額の実際の減少を確認し市民満足度向上を実証

## テーマ選定理由（なぜオンライン広告詐欺か）

- **国民的合意が得られやすい**: 詐欺対策は党派を問わず支持され、規制対象が外資系PF企業のため抵抗が少ない
- **[[ミニ・パブリックス]]構築が容易**: 被害者がインターネットユーザーのためオンラインパネルで対応可能
- **緊急性が高い**: 毎月被害者が出ており、1年以内に結果を出せる可能性
- **台湾での実績**: 2024年の台湾の市民熟議を経て、[[KYA]]・透明性義務・削除義務・罰則を含む規制が進み、詐欺被害額が30分の1に減少

## 市民熟議（[[討論型世論調査]]）の結果

分析サンプル N=283（討論前T1／資料読了後T2／討論後T3の3波すべてに回答し、当日出席した参加者）。賛成＝0〜10尺度で6以上。

**合意があった政策（討論後に賛成70%以上・11項目）**

| 政策 | 討論後の賛成率 |
|------|------|
| 広告主の身元確認義務化（[[KYA]]） | 94.7% |
| 投資系グループチャット開設者の本人確認 | 88.9% |
| 24時間以内の削除責任 | 86.1% |
| 高リスク広告のAI事前審査 | 83.5% |
| 利用者の実在確認 | 81.8% |
| AI生成広告のラベル義務 | 81.4% |
| 被害削減の実行計画提出と監視 | 78.9% |
| 被害への賠償責任 | 74.8% |
| 通報窓口の運営：政府 | 73.6% |
| 通報窓口の運営：第三者機関 | 73.5% |
| 外部監視用APIの無償公開 | 71.1% |

**賛同が得られなかった政策（5項目）**: コミュニティノート義務化 65.9%（資料読了後75.3%）、市民団体の差止・賠償請求権 59.7%、通報窓口の運営：民間 59.1%、市民団体への財政支援 44.8%、通報報奨金制度 23.5%（資料読了後46.7%）

**読み取れる傾向**:
- 資料を読んだだけの「情報効果」（T1→T2）では、SNS広告や政府・プラットフォームへの信頼が下がる一方、責任認識と中核政策への支持が底上げされた
- 討論の「討議効果」（T2→T3）では設問が分化し、KYAや政府への信頼は上がる一方、通報報奨金・市民団体への権限付与・財政支援などは大きく下がった。提言書は「熟議は要求を積み上げる場ではなく、実行すべき対策を選び分ける場として機能した」と整理している

## 提言書の内容（2026年8月版・10月版）

提言は2つ。

1. **自民党PT提言を速やかに実行すべき**: 2026年5月の自民党PT提言が掲げた法整備の検討4項目（規制対象の明確化と透明性、[[KYA]]義務、削除の枠組み、担保措置）と専用通報サイトの構築は、いずれも市民の合意を得た
2. **日本独自の4政策を法整備の検討対象に加えるべき**: 投資系グループチャット開設者の本人確認、高リスク広告のAI事前審査、外部監視用APIの対象を限定した無償開示、コミュニティノートの義務化（70%に届かなかったが、低下の理由が制度の是非ではなく運用の懸念だったため含めた）

「利用者の実在確認」は81.8%の支持があったが、影響が詐欺広告対策を超えてSNS全体に及ぶため提言の射程外とした。支持が得られなかった4政策は提言しない。取捨選択を行ったのは市民ではなく機構自身であることを明記し、根拠となる数値と討論内容を第2章に示している。

## 行政との連携（警察庁・金融庁）

- **警察庁（5月20日）**: 組織犯罪対策第二課は[[ストップ詐欺広告]]を「最新トレンドの把握」に有用として既に活用。警察側はURLとデータセット（全件）の提供を希望し、ガイドライン非該当のグレー案件も幅広く提供してほしいと要望（削除されなかった実績の蓄積が将来の法制化の立法事実になるため）。削除要請ステータスの可視化、IHC（インターネット・ホットラインセンター）との窓口一本化、YouTube等の「報告できないUX」問題なども論点になった
- **警察庁（5月26日）**: 当面はメールでExcelデータ（キャプチャ画像付き）を共有し、セキュリティ審査後に専用管理画面の導入を検討する方針で合意。IHCの運用ガイドライン改定（秋の早い段階を目標）後はIHCルートでの削除要請も視野
- **金融庁（5月20日）**: 監督局証券課が対応。窓口に寄せられる被害情報は最初にクリックした広告を特定できないものが多く、広告段階で詐欺を捕捉・通報できるツールへの期待が示された。一方、投資グループチャットを金融庁登録業者に限定することは法律論として難しいとの見方
- **横展開フレーム資料**では、警察庁が「ストップ詐欺広告を毎日見ている、これに基づいてプラットフォーマーへの削除通知申請をしていく」と表明したことを、市民の通報（声）が行政の実行に接続した到達点として位置づけている

## プロセス再現書と横展開

- **市民熟議プロセス再現書**（2026年8月、執筆中）: 想定読者は、やる気のある市民、行政・政治側（特に地方）、シビックハッカーや学術関係者。市民熟議を署名・パブコメ・世論調査・タウンホール・[[ブロードリスニング]]と比較し、「情報を得た後の判断とその変化」を測る手法として位置づける。費用と正統性のバランス（層化抽出・専門家監修は必須、規模や専門家の関与は調整可能）、熟議の結果を政策につなげる方法、「市民熟議を超えて」として[[ストップ詐欺広告]]の創り方（立法事実の蓄積と継続的モニタリング、リファレンスプロダクトの設計原則）を扱う
- **横展開フレーム資料**: 約5ヶ月で「台湾視察→4ステップ→政策接続・行政連携」を一周したと整理。別テーマ・別地域で再現する際、最も代替が難しいのは「政策接続の経路」と「統括の顔役」で、技術や世論喚起は外部資産で補えるとする
- **Coreloop 2.0**: 自民党PMT研究会側の関心を受け、ブロードリスニング（PoliPoliとDD2030がそれぞれ実施）→ワークショップ（政治家側）→DP（DD2030／PRANCE）という分担案が検討されている（2026年8月時点）

## [[ストップ詐欺広告]]（Reference Product）

台湾の「Anti-Fraud」と同様の構造。市民がオンライン詐欺広告を通報し、事務局が判定・ラベリングする。

- 4月時点で500件以上の通報、5月下旬時点で1,000件超（累計URL約5,000件）、7月時点で1,200件超を収集
- 投資系・なりすまし系広告にラベリング。判定区分は「詐欺」「高リスク」「調査中」「白」
- 2026年5月にラベル付けAIを本番環境に投入。6月時点で体感精度約8割、作業時間は手作業の約1/3
- 2026年5月の警察庁との意見交換を経て、通報URL・画像を警察庁へ共有し、プラットフォームへの削除要請につなげる連携を開始
- 官公庁ユーザーが使えるよう、ISMAP登録済みのGoogle Cloud中心の構成へ移行する計画を策定
- 台湾の Gogolook との連携を進行（NDA締結待ち、2026年6月時点）

## DP（[[討論型世論調査]]）の設計

- **規模**: 当初300名で計画し、約1,500名の参加意向者から層化抽出で330名を確定。実際の出席は287名、分析サンプルは283名
- **調査会社**: クロス・マーケティング社
- **費用**: 約580万円（当初見積）
- **謝礼**: 1万円（Amazonギフト券）。事前クイズ回答・当日事前アンケート・討議参加・事後アンケートの4条件を満たした参加者が対象
- **層化抽出**: 年齢3層 × 性別 × 地域7区分（42グループに人口構成比で割り当て）
- **ツール**: Stanford SODP（メイン）。全体会議はYouTube Live（リンク制限）＋StreamYard
- **学術監修**: 慶應義塾大学 KGRI-PRANCE（設計・討論資料・質問紙・分析）、スタンフォード大学 Deliberative Democracy Lab（手法の監修、プラットフォーム提供）
- **専門家委員会**: 討論資料と質問紙に助言し、当日の専門家パネルに回答者として参加

## 国際連携

- **台湾**: MODA（デジタル省）・NYCU等の関係者にヒアリング（2026年1月視察）
- **オードリー・タン**: 自民党PTでの共同説明、オンラインヒアリング
- **Stanford大学**: Alice（Deliberative Democracy Lab）がSODPのβテスターとして協力。2026年6月21日のオンライン熟議では Stanford Deliberate platform を使った当日運用を確認。提言書10月版では同Labが「討論型世論調査の手法の監修、オンライン討論プラットフォームの提供」として学術監修に名を連ねる
- **若尾真也**: Texas大学。日本初のオンラインDP経験者。2026年5月下旬に当日進行管理表の更新で協力
- **Gogolook**: 台湾の詐欺対策企業。[[ストップ詐欺広告]]との連携を2026年5〜6月に調整
