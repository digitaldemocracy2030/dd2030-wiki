# 週次全体定例 議事録

## 概要

`raw/minutes/weekly-general-meeting.txt` は、dd2030全体定例の議事録。各プロダクト・プロジェクトの近況、コミュニティ運営、渉外、相談事項を横断的に追える基礎ソースである。

## 収録範囲

- 主な期間: 2025年3月22日〜2026年9月26日（2026年10月30日に再取得。10月の回は取得時点で未記入）
- 形式: 週次全体定例の共有・相談・交流メモ
- 補足: 日付順は新しい回から古い回へ並ぶ箇所が多い

## 主な内容

- [[広聴AI]]、[[いどばた]]、[[Polimoney]]、[[コアループ]]、[[ブロードリスニング本]]などの週次進捗
- Slackコミュニティの人数推移、定例運営、GitHub権限整理、オンボーディング課題
- 外部からの問い合わせ、メディア露出、自治体・政党・民間組織との接点
- 2026年1月以降の[[コアループ]]週次レポートと、[[ストップ詐欺広告]]関連の進行
- 2026年4月11日の[[AIディープサーベイ]]実施中共有と、法規制検討の基礎資料としての位置づけ

### 2026年4月18日〜9月26日の回（2026-10-30 取り込み）

- **メンバー数**: 1,574（4/18）→ 1,629（9/26）。毎回の冒頭で推移を記録
- **一般社団法人化（5/2〜）**: コアループのクラウドファンディングで任意団体では銀行口座が開けないと分かり、法人化を決定。「2030」は時限的なので法人名には使わず、フラッグシップ・プログラム名として残す。名称候補を募集し、6月1日に[[デジタル民主主義推進機構]]に決定
- **Slack ログの公開方針（5/9）**: 西尾が、公開チャンネルのログは当初から [[OSS Weekly Reporter]] で GitHub に蓄積されていたことを再確認し、「公開チャンネルのログはここにある」と分かる形に整理して CC-BY にする方針を提示。1週間の猶予後に着手（→ [[Slackログアーカイブ]]）
- **Slack→Discord 移行の議論（5/9、5/16、6月〜9月）**: 法人化のタイミングで切り替えてもよいという案、Slack の運用支援機能が軒並み有料で月額数百万円になる問題、Discord はパブリックルームがデフォルトインでオンボーディングが安いという tokoroten の指摘、1,600人の資産を切り捨てる懸念。結論は「全体で移るよりチームごとに」「どちらでもログが出力されればよい」。7月に政治家・官庁関係者の懸念を Slack で確認し、懸念なしのため「正式な移行ではない」と明記のうえ試験的に全体告知する方向
- **dd2030-wiki の公式化（7/11）**: 西尾が作っていた本 Wiki をコピーして公式 Wiki とした。OSS Weekly Reporter の代替的な活動把握先、ガイドブックからのリンク先として継続利用するため、モアイ（小野翔太）が依頼
- **ガイドブック（6/13〜9/26）**: 7月頭にたたき台予定 → 9月に「たたき台ができたので Discord で公開し意見を募りながら編集」（10/2 公開。→ [[topics/guidebook-activity-status-debate|ガイドブックの「動いているプロジェクト」表記と活発度の扱い]]）
- **広聴AI**: 4〜5月は書籍原稿の出版社引き渡し前の最終調整と新事例の追加、5/16 に「出版社に原稿を引き渡して組版中」。新たな自治体との話が進行（首長・担当課の温度感が高い）。5/30 にプラグイン化、6/6 に Azure デモ環境の散布図不具合修正と開発者向け Wiki 作成、7/4 に横浜市のブロードリスニング事例、7/18 に tokoroten のブラウザ版（ペライチ HTML）。4/25 のコミュニティ運営定例では「エンジニアでなくても使えるように」との要望があり、マニュアル整備で応じる方針
- **いどばた**: 5月に岩永さん（和歌山県議）が和歌山県版いどばたの記者会見。6月に新規メンバーがリポジトリを触り始め、7月は「Deploy をしやすくしたい」
- **Polimoney**: 4月に Ledger（会計ソフト）の UI/UX 担当が見つかる。5月に岩永さん・中村幸信さんの選挙運動費用収支報告書を公開、API ドメインを設定。6月に DB 設計の見直しが必要と判明し、7月に DB と API を整理してマージ（拡張しやすくなった）。8月は Ledger の UI を抜本的に見直し、8/2 のサミットに向けスクショを用意
- **コアループ**: 4〜6月の週次レポート（鈴木・縄田・Ryoma・小倉・赤澤・西田の各リード）。4/18・4/25 のワークショップ、5/16 の政策ワークショップ、5/18 の専門家会議、6/19 に自民党 PT の提言が承認されストップ詐欺広告が言及、6/21 に Stanford 監修の討論型世論調査（DP、確定参加者330名）。警察庁の組織犯罪対策課との連携開始（「ストップ詐欺広告を毎日見ている」）。クラウドファンディングは384,300円で終了。7月下旬に警察庁との提携発表、8月下旬に記者会見予定、報告書・提言書を執筆中。10/3 の経済法フォーラムで紹介予定
- **デジタル民主主義サミット（8/2）**: 5月末から `#dd_prance_event2026` で企画、パラレルセッションを公募。8/8 に録画4セッションを公開、残り4セッションは最終確認中（→ [[events/2026-08-02-digital-democracy-summit|デジタル民主主義サミット2026]]）
- **各プロジェクトの戦略会議（8/8）**: 鈴木健とプロジェクトメンバーがオープンに話す。目的は現状の課題をボードメンバーがサポートし、1年の方向性を話すこと。9月以降に広聴AI（＋関）、いどばた（＋ぶるーも）、Polimoney で実施。9月に「健さんと話す会 9/18」が提案され、10月に [[events/2026-10-24-polimoney-strategy-meeting|Polimoney（10/24）]]、[[events/2026-10-28-idobata-strategy-meeting|いどばた（10/28）]]が開催
- **その他**: GitHub と Slack の権限整理（鈴木健・西田に owner 移譲）。ビルダーズドメインを10月半ばに渡す。website のメニューでコアループを最上位に。`dd2030.org/newcomer/` の由来確認。Outline（ドキュメント管理）の試用

## Wikiでの使い方

このファイルは「プロジェクト全体の温度感」を見る入口として使う。特定プロダクトの詳細は専用議事録に分かれているため、全体定例は時系列の確認や横断的な接続関係の確認に向いている。
