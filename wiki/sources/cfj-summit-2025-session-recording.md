# Code for Japan Summit 2025「デジタル民主主義ブームを振り返る」録画要約

## ソースの概要

[[events/2025-11-29-code-for-japan-summit|Code for Japan Summit 2025]]（2025-11-29、国連大学）のセッション「デジタル民主主義ブームを振り返る」の録画。Code for Japan の公式YouTubeチャンネルで2026年1月30日（日本時間）に公開された（39分30秒）。

| 登壇者 | 立場（セッション内の自己紹介による） |
|---|---|
| 関治之 | モデレーター（Code for Japan） |
| 山口さん | Code for Japan 理事。リクルートでAIガバナンスを担当し、以前は行政でテクノロジー政策に関わっていた（フルネームはASRで不確か） |
| 鈴木健 | 東京大学。スマートニュース会長、『なめらかな社会とその敵』著者、[[デジタル民主主義2030]]ボードメンバー |
| 西尾泰和 | サイボウズ・ラボ |

前半約30分が導入と3人の発表、後半約8分がSlidoに寄せられた質問をもとにした討論。

要約はYouTubeの**日本語自動生成字幕（ASR）**をもとに作成した。人名・数値に誤認識が残るため、**逐語の正確さは保証されない**。引用するときは元動画を参照すること。

## 発表

### 関治之: 導入

- 「そもそもブームは来たのか」から問いを立てた。論文での定義は「ICTを使って政治的民主主義を強化する、または市民の民主的コミュニケーションへの参加を促すもの」。
- Googleトレンドでは、2024年5月後半から「デジタル民主主義」の検索がシビックテックと同程度まで伸びており、ひとまず波が来たとは言える。
- AI以前から、Code for Japan は市民参加プラットフォーム Decidim を提供しており、国内20か所以上で使われている。AIの発展で声の集め方が変わり、[[広聴AI]]、D-Agree、[[Polis]] などが出てきた。

### 山口さん: 技術はツール、舵取りは人間

- テクノロジーは社会課題を解決するツールであり、SF的なイメージで捉えないことをセッションの最初に確認したい。
- SNSやフェイクニュースの問題は技術のせいにされやすい。しかし噂を広めたい、悪口を言いたいといった人間社会に昔からある性質を、技術が見える化し加速しているという面がある。技術がどれだけ進んでも、社会の舵取りのオーナーシップは人間が持ち続けるべき。
- AIは社会の鏡で、無意識のバイアスに気づかせてくれる。デジタル民主主義は技術的ソリューション主義ではなく、ツールを使ってどう社会をデザインするかという、人間による主体的な意思決定の取り組みだ。

### 鈴木健: なぜデジタル民主主義2030を始めたか

- 民主主義はそれ自体がテクノロジーの一つ。技術が進めば民主主義もアップデートされるのが当然で、良い方向に進むか悪い方向に進むかは自分たち次第。
- 2025年1月に安野貴博さんと[[デジタル民主主義2030]]を立ち上げた。安野さんは政党を立ち上げてボードを退任し、鈴木さんが引き継いだ。
- 「ブームなのか」への答えは、データを見る限り**まだブームは起きていない**。ブームは目的ではなく、小さな成功事例を積み上げていくことが大事。
- 自身の経歴: 1990年代にインターネット上の政策比較のプロジェクトを立ち上げた。2009年に第1回Web学会シンポジウムを開き、投票を委任できるネットワーク型の投票システム（リキッドデモクラシーに近い考え方）を発表した。『なめらかな社会とその敵』の根本の問いは「複雑な世界を複雑なまま生きることはいかにして可能か」。
- 2010年代、スマートニュースの米国展開で地方を回り、分断を見た。分断はその後、暴動、「Stop the Steal」、2021年1月の連邦議会占拠へと政治的暴力の段階に進んだ。バーバラ・ウォルターの内戦研究（民主主義と独裁の中間の国ほど内戦が起きやすい）を紹介した。
- 世界の民主主義指数は冷戦後に上がって横ばいになり、この10年で冷戦末期の水準まで下がった。2022年ごろからは新冷戦の構造に入っている。オードリー・タンは日本を「民主主義の最後の砦」と呼ぶ。日本でも今後5〜10年で厳しい分断社会になりうるので、いまデジタル民主主義をつくり、世界に輸出する必要がある。
- オードリー・タンとの出会いを通じて、『Plurality』が『なめらかな社会とその敵』と「双子のような本」だと分かったことも、立ち上げのきっかけになった。

### 西尾泰和: デジタル民主主義の川の流れを見る（5分版）

- 事前に練習したら33分かかった内容を、残り5分で話した。中身は[[sources/cfj-summit-2025-river-talk|事前動画]]と同じで、「ブーム」ではなく川の流れという見方から、Polis→ひまわり学生運動→vTaiwan→Talk to the City→日本のブロードリスニング→DD2030と周辺の新しいツールへと系譜をたどった。
- 締めの言い回しは事前動画と少し違う。事前動画は「どれが有益だったかは5年後に振り返って分かる」。当日は「30年後に振り返って、これがあったから民主主義は死なずに済んだと分かるかもしれない」と言い、「connecting the dots」として色々な試みを勧めた。

## 討論（Slidoの質問から）

- **市民も地方議員も当事者意識がゼロだが、それでよいか**
  - 鈴木: ゼロではない。気づいて動いている政治家や自治体はあちこちにある。当事者意識は潜在的にあり、簡単に参加できるツールができれば顕在化する。
  - 山口: そもそもデジタル民主主義に当事者意識は必要なのか、とも問える。
  - 西尾: なくてよい。Twitterに意見を書く人は既にいるが、その声が政府に届かない。自分の声を届けたいという気持ちこそ当事者意識であり、ツールで届くようになれば使われる。
  - 鈴木: 一定数は必要。いまの参加は「4年に1回の投票（低コストだが影響が小さい）」か「市民運動（影響は大きいが人生の時間を大きく割く）」の両極しかない。技術でその間のなめらかな関わり方をつくれる。
  - 西尾: 参加の最初の一歩が分かりにくいことが課題。エンジニアでなくてもドキュメント整備などで参加できる。
- **なぜ日本が民主主義の最後の砦なのか**
  - 鈴木: 結果論だが、55年体制が長く続き、地方への再分配で経済格差が諸外国ほど広がらなかった。
- **デジタル民主主義のツールはデジタル好きしか使わず、デジタルデバイドが広がるのでは**
  - 西尾: 実際の利用者はデジタル好きが多い。デジタルが苦手な人に使えと言っても無理なので、話を聞きに行く人の側を技術で支援する。AIで文字起こしのコストは従来の約10分の1になった。数年で音声でやり取りできるようになればハードルは大きく下がる。好きな人と苦手な人が分断されるという考え方自体が間違いで、その壁をなめらかにするのに技術を使える。
  - 山口・関: アクセシビリティは上がる。すべてをデジタルに置き換える必要はなく、アナログなプロセスと組み合わせて改善すればよい。
- **合意形成の良さを測る指標を作れば、手法のランキングができるのでは**
  - 西尾: 合意率が上がることが本当に正しいのか。うまく洗脳すれば合意率は上がる。KPIを立てること自体が正しくない可能性がある。
  - 鈴木: 合意形成は手段で、最終的に上げるべきは市民の生活の満足度。中間指標だけを追うと最終結果が悪くなりうる。

## 使いどころ

- [[events/2025-11-29-code-for-japan-summit|Code for Japan Summit 2025]] のセッション全体を確認するときの一次資料。西尾さんの発表の完全版は[[sources/cfj-summit-2025-river-talk|事前動画要約]]を参照。
- DD2030の設立動機（鈴木健さん）、「ブームはまだ起きていない」という自己評価、デジタルデバイドとKPIへの答え方を、一つの場で確認できる。
- Talk to the City が使われた vTaiwan の事例で、集まった人数が事前動画（「4000人以上」）と当日（「400人」）で食い違って聞こえる。どちらもASRのため数値は未確認。
